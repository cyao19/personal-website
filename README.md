# Cynthia Yao — Personal Website

A responsive, single-page personal website with warm beige, periwinkle sculpture, nature-inspired photography, and subtle motion.

## Motion
- Cursor-responsive sculptural hero image
- Animated fine-line curves
- Scroll-triggered text and image reveals
- Subtle scroll parallax on the About image
- Scroll progress indicator
- Smooth section navigation and hover interactions
- Respects `prefers-reduced-motion`

## Customize
Edit `index.html` and replace text in square brackets with your own. The Blog and Resume rows are deliberately placeholders, **not** live links. Replace them with real content when available. Images are in `assets/`.

## Publish to GitHub Pages
Extract the ZIP, upload the **contents** (`index.html`, `assets/`, `README.md`) to the repository root, and commit. In GitHub repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)` and Save.

No build tools or dependencies are required. The Google Fonts import requires an internet connection; fallback fonts are provided.
